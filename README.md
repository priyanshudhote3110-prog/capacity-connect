> **Smart India Hackathon 2026 | Problem Statement: SIH26075**  
> **Theme:** Smart Education | **Ministry:** Ministry of Earth Sciences (MoES)

## What is Capacity Connect?

A centralized Learning Management System (LMS) for training scientists and employees across 6 autonomous institutes of MoES:

- **IMD** — India Meteorological Department
- **INCOIS** — Indian National Centre for Ocean Information Services
- **IITM** — Indian Institute of Tropical Meteorology
- **NCMRWF** — National Centre for Medium Range Weather Forecasting
- **NIOT** — National Institute of Ocean Technology
- **NCPOR** — National Centre for Polar and Ocean Research

## Features

- 🎭 **Role Switcher** — Switch between Learner, Trainer, and Admin roles
- 📚 **Course Catalog** — 6 domain-specific training modules
- 🎥 **Interactive Classroom** — Video player with progress tracking
- 📝 **Auto-Graded Quiz** — 5 real Earth Science questions with timer
- 📜 **Digital Certificate** — Government-style certificate with QR code verification
- 📊 **Skill-Gap Heatmap** — Institute-wise competency audit matrix (Admin)
- 🏆 **Leaderboard** — Knowledge Points ranking
- 🔍 **Certificate Verification** — Public verification portal

## How to Run Locally

1. Clone this repository
2. Open `index.html` in any web browser (Chrome / Edge / Firefox)
3. No server or Node.js required!
